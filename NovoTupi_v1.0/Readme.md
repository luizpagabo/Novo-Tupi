NOVO TUPI

Version 1.0

Created by Luiz Pagano.
Originally conceived in 2013.

Released under the SIL Open Font License 1.1.

Novo Tupi is a typeface inspired by the writing system developed for the Tupi language.

Installation

Windows
Double-click the .ttf file and click Install.

macOS
Double-click the .ttf file and click Install Font.
