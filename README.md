# Alfabeto Novo Tupi

O **Alfabeto Novo Tupi** é um sistema de escrita criado por Luiz Pagano como parte do projeto cultural **Tupi Pop**.  
Ele busca revitalizar a identidade indígena brasileira por meio de uma tipografia própria, inspirada no Tupi Antigo e apresentada como uma alternativa estética e simbólica ao alfabeto latino tradicional.

---

## 📖 Contexto
- Criado no século XXI por Luiz Pagano, dentro do projeto **Tupi Pop**.  
- Objetivo: oferecer ao Brasil um novo imaginário nacional, sofisticado e original, com base na herança indígena.  
- Reconhecido internacionalmente pelo site [Omniglot](https://www.omniglot.com/conscripts/novotupi.htm), referência mundial em sistemas de escrita.  
- Classificado como um **script construído (constructed script)**, inspirado no Tupi Antigo, língua que deu origem ao Nheengatu (Tupi Moderno).

## 💻 Instalação da fonte
### Windows
1. Baixe o repositório (`Code → Download ZIP`) ou clone com `git clone`.
2. Extraia os arquivos da pasta `NovoTupi_v1.0`.
3. Clique com o botão direito sobre o arquivo `.ttf` → **Instalar**.
4. Reinicie o computador para aplicar.

### MacOS
1. Baixe e extraia os arquivos da pasta `NovoTupi_v1.0`.
2. Abra o arquivo `.ttf` no **Font Book**.
3. Clique em **Instalar Fonte**.
4. Reinicie o sistema para aplicar.

### Linux
1. Copie os arquivos `.ttf` para a pasta `~/.fonts` ou `/usr/share/fonts`.
2. Atualize o cache de fontes com `fc-cache -fv`.
